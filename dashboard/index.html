How the value is built

  1. Base: TVL × 0.40 — a new token is typically worth a fraction of the value its protocol secures.
  2. Growth: × (1 + 0.8 × 7-day TVL change), change clamped to −50%…+100%. An unreported change counts as neutral. One wild week cannot dominate.
  3. Age: × (1 + 0.4 × days-with-no-token ÷ 1460). A four-year track record with no token yet earns up to +40%. No listing date counts as 180 days.
  4. Reach: × (1 + 0.02 per extra chain, capped at 15). Wider deployment earns a modest premium.
  5. Category prior: × 0.97–1.10, a small documented tilt (Risk Curators 1.10, RWA 1.08, Dexs / Lending 1.05, the rest 1.00, uncategorised 0.97).

Every input comes from the snapshot row itself. No name or slug is ever hardcoded, and the board never predicts whether or when a token is issued — it prices what one would be worth if the record stayed as it is. “Records no token” means DefiLlama carries no token for the protocol, not that it has none.

What is left out, and why

Protocols whose token already trades are listed under “Live token” and are never ranked as launch candidates. A further set of rows that record no token is also left off the ranked board: centralised exchanges, bridges, liquid-staking and restaking products, wrapped or staked products of a token that already trades, and versioned copies. They are not launches waiting to happen, and the count of each group is shown in the header above.
